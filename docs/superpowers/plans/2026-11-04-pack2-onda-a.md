# Pack 2 · Onda A: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> Execução pelo fluxo do Maestri (`docs/fluxo.md`): um card por task (IM-30 em diante), andar por task, dev → VAR → QA → merge, **deploy com backup manual antes**.

**Goal:** Entregar a onda A do pack 2: compartilhar, reações com emoji, post fixado, hashtags, prompts favoritos, bio e capa do clube, denunciar/ocultar e posts só de texto, sem perder nenhum dado de produção.

**Architecture:** Só migrações **aditivas** no Prisma: colunas novas com default e tabelas novas. A curtida vira reação **ganhando a coluna `emoji` com default `'❤️'`** na tabela `Like`, então toda curtida existente vira ❤️ sem script de conversão. Os endpoints antigos continuam iguais (o front antigo segue funcionando até atualizar) e os novos entram ao lado. Hashtags são buscadas na hora com `unaccent` + regex no Postgres, sem coluna nova.

**Tech Stack:** a mesma da v1 (Nest 12 + Prisma 7 + Postgres 17; React 19 + Vite). Nenhuma dependência npm nova. Extensão `unaccent`, que já vem no Postgres 17 oficial.

**Spec:** `docs/superpowers/specs/2026-11-04-instamanager-pack2-design.md` (§4.1, 4.2, 4.5, 4.6, 4.11, 4.12, 4.14, 4.15)

## Global Constraints

- **Migrações só aditivas.** Nada de `DROP`, `RENAME` ou `ALTER ... NOT NULL` sem default. A migração é testada contra um **dump de produção** antes do deploy (Task A5).
- **Compatibilidade:** `PUT/DELETE /api/posts/:id/curtida`, `curtidas` e `curtiu` continuam existindo e com o mesmo sentido (curtida = reação ❤️; `curtidas` = total de reações; `curtiu` = tem reação).
- **Reações:** exatamente `['❤️','🔥','😂','😮','😢','👏']`, uma por pessoa por post.
- **Post de texto:** 0 imagens e `texto` de 1 a **500** caracteres. Post com imagens continua com legenda de até 2200.
- **Fixados:** no máximo **3**. Só o admin fixa.
- **Bio do clube:** até **300** caracteres. **Capa:** JPEG 1500×500 comprimido no celular, ≤ 3 MB, validado com `ehJpeg`.
- **Ocultar pelo admin:** reversível e invisível para quem não é admin, em todo lugar (feed, `/p/:id`, galeria, clube, tag).
- **Prévia do link:** genérica (`og:title` "InstaManager", `og:image` = ícone 512), sem conteúdo de post.
- Português do Brasil, testes em toda lógica nova, commits com `[IM-N]`, sem dependência nova.

## Review Focus

1. **Curtidas reais de produção** viram ❤️ com a mesma contagem por post depois da migração. Teste na Task A5, com o dump.
2. **Post só de texto** em telas que assumem `imagens[0]` (grade do clube, galeria, compartilhar, card) não pode quebrar nem aparecer na galeria. Testes nas Tasks A1 e A3.
3. **Post ocultado pelo admin** não aparece para quem não é admin em nenhuma lista e responde 404 em `/api/posts/:id`. Teste na Task A2.
4. **Fixar o 4º post** responde `409 LIMITE_FIXADOS`. Post apagado ou ocultado sai dos fixados. Teste na Task A1.
5. **Hashtag:** `#Contratação` encontra `#contratacao`, `#` dentro de URL (`site.com/#x`) não vira tag e `#` sozinho não vira link. Testes nas Tasks A2 e A4.

### Task A1: Back · reações, texto e fixados · IM-31

**Files:** `back/prisma/schema.prisma`, `back/prisma/migrations/<ts>_onda_a_reacoes_texto_fixados/`, `back/src/interacoes/*`, `back/src/posts/*`, `docs/api.md`. Test: `back/test/onda-a-reacoes.e2e-spec.ts`.

**Interfaces (Produces):**
- Schema:
  - `Like.emoji String @default("❤️")`;
  - `Post.texto String?` (com `caption` continuando para legenda de post com imagem);
  - `Post.pinnedAt DateTime?`.
- Rotas:
  - `PUT /api/posts/:id/reacao {emoji}` → `204`. `400 EMOJI_INVALIDO` fora da lista. Troca a reação se já houver uma.
  - `DELETE /api/posts/:id/reacao` → `204`.
  - `PUT /api/posts/:id/curtida` vira um apelido de reação ❤️.
  - `POST /api/posts` aceita 0 arquivos + campo `texto` (1–500). Com 0 arquivos e sem texto → `400`.
  - `PUT|DELETE /api/admin/posts/:id/fixar` 👑. `409 LIMITE_FIXADOS` no 4º.
  - `GET /api/posts` sem `antes` e sem `clube` traz `fixados: Post[]` (ordem por `pinnedAt` desc), e esses posts não se repetem em `itens`.
- `Post` ganha os campos:
  - `texto|null`;
  - `fixado: boolean`;
  - `reacoes: [{emoji, total}]` (até 3, maior total primeiro);
  - `minhaReacao: string|null`.
- A galeria ignora posts de texto.

  - `emoji fora da lista → 400`;
  - `post de texto 0 arquivos + 'Rodada boa' → 201 com texto e imagens []`;

  - `0 arquivos sem texto → 400`;
  - `admin fixa 3, o 4º → 409 LIMITE_FIXADOS`;
  - `não-admin fixar → 403`;
  - `feed pág. 1 traz fixados e não os repete em itens`;
  - `apagar post fixado tira dos fixados`;
  - `galeria não lista post de texto`.
